# پوسته دایرکتوری و خرید و فروش زمین زمین‌یاب (ZaminYab Directory Theme)

سامانه تخصصی، بومی، راست‌چین (RTL) و موبایل‌محور (Mobile-First) خرید، فروش، رهن و اجاره انواع زمین و ملک در سراسر کشور، الهام گرفته از سایت‌های نیازمندی مطرح کشور ولی کاملاً اختصاصی برای حوزه اراضی.

---

## 💎 ویژگی‌های کلیدی پوسته
*   **طراحی کاملاً راست‌چین و موبایل‌محور:** تجربه کاربری بی‌نظیر روی موبایل و تبلت با استفاده از فونت استاندارد و زیبای **شبنم** به صورت محلی و خودکار.
*   **سیستم ثبت آگهی چندمرحله‌ای پیشرفته:** دارای فرم ۶ مرحله‌ای ثبت آگهی به همراه موقعیت‌یابی جغرافیایی با کلیک روی نقشه (OpenStreetMap/نشان).
*   **پنل کاربری و داشبورد اختصاصی فرانت‌اند:** کاربران بدون نیاز به دسترسی به پنل مدیریت وردپرس (wp-admin)، می‌توانند آگهی‌های خود را مشاهده، ویرایش یا به صورت امن حذف کنند.
*   **آفلاین و بهینه‌سازی کامل بدون وابستگی:** عدم استفاده از کتابخانه‌های خارجی سنگین، کدهای بهینه‌سازی شده با بهترین امتیاز در سنجه‌های وب حیاتی (Core Web Vitals).
*   **آیکون‌های کاملاً بهینه شده inline SVG:** ترسیم آیکون‌ها به صورت مسیرهای بهینه شده SVG در فایل `inc/svg-icons.php` بدون نیاز به بارگذاری فونت آیکون‌های خارجی سنگین.
*   **اتصال هوشمند به پیام‌رسان‌های بومی:** ایجاد دکمه‌های مستقیم تماس برای شبکه‌های اجتماعی بومی کشور (بله، روبیکا، ایتا).
*   **سیستم فیلتر پیشرفته تودرتو:** فیلترینگ و مرتب‌سازی بر اساس متراژ، قیمت، نوع سند، نوع کاربری، انشعابات، رهن و اجاره و کاربری زمین به صورت هوشمند و کاملاً رسپانسیو.
*   **امنیت و حفاظت بالا:** جلوگیری کامل از حملات Stored XSS، ایمن‌سازی کامل فرم‌ها با متدهای اعتبارسنجی Nonce وردپرس و فیلترینگ ورودی‌ها با `sanitize_text_field`.

```text
/zaminyab/

  index.php              - قالب پیش‌فرض آرشیوها و مقالات
  front-page.php         - صفحه اصلی پیشرفته و دایرکتوری زمین
  header.php             - هدر یکدست و تمام‌عرض به همراه منوی چسبان
  footer.php             - فوتر رسپانسیو به همراه ناوبری چسبان موبایل و لینک اجتماعی
  single.php             - صفحه جزئیات آگهی به همراه کاروسل تصاویر و موقعیت نقشه
  page.php               - الگوی یکسان و متوازن صفحات وردپرس
  archive.php            - قالب فیلترها و کاتالوگ فروش زمین
  search.php             - قالب جستجوی همگام و فیلترها
  404.php                - صفحه اختصاصی خطای ۴۰۴ در استایل زمین‌یاب
  /assets/
    /css/
      main.css           - شیوه‌نامه‌های اصلی، رسپانسیو، کادرها و فونت‌ها
      rtl.css            - بهینه‌سازی جهت لود RTL فارسی
      admin.css          - شخصی‌سازی پیشخوان مدیریت و راهنما
      login.css          - زیباسازی بومی صفحه ورود وردپرس
    /js/
      main.js            - دیالوگ‌باکس‌های بومی فارسی و منوهای کشویی
      search.js          - کنترلرهای جاوا اسکریپت فیلترها
      map.js             - راه‌اندازی و تعاملات نقشه Leaflet
      submit-listing.js  - فرم‌ساز چندمرحله‌ای و پیش‌نمایش فایل‌های آپلود
  /inc/
    setup.php            - پیکربندی‌های اصلی پوسته و ایجاد خودکار برگه‌ها
    taxonomies.php       - ثبت دسته‌بندی‌های نوع زمین، سند، کاربری و لوکیشن‌ها
    meta-boxes.php       - ویژگی‌های پیشرفته اراضی (حقابه، نوع خاک، رهن و اجاره)
    search-handler.php   - ادغام متغیرهای فیلتر با کوئری اصلی با pre_get_posts
    frontend-submit.php  - آپلودر امن بدون تداخل لایسنس با wp_handle_upload
    svg-icons.php        - سیستم مدیریت آیکون‌های بومی
    helpers.php          - توابع تبدیل تاریخ به جلالی و فرمت قیمت‌ها
    documentation-panel.php - مستندات پیشرفته پیشخوان مدیریت
```

## 📋 لیست شورت‌کدهای اختصاصی قالب
شما می‌توانید شورت‌کدهای زیر را در برگه‌ها یا بخش‌های مختلف سایت قرار دهید:
*   `[zaminyab_search]`: فرم کامل جستجو و فیلترینگ اراضی.
*   `[zaminyab_submit_listing]`: فرم چندمرحله‌ای و پیشرفته ثبت آگهی جدید.
*   `[zaminyab_latest_listings count="8"]`: نمایش جدیدترین زمین‌های ثبت شده.
*   `[zaminyab_featured_listings count="4"]`: نمایش زمین‌های ویژه در صفحه اصلی.
*   `[zaminyab_user_dashboard]`: پنل کاربری مدیریت آگهی‌های من (ویرایش/حذف).
*   `[zaminyab_favorites]`: نمایش آگهی‌های نشان‌شده کاربر.

## 👶 راهنمای ایجاد پوسته فرزند (Child Theme)
برای اعمال کدهای سفارشی بدون از دست رفتن فایل‌ها با بروزرسانی قالب، از قالب فرزند استفاده نمایید:
1. یک پوشه در مسیر `wp-content/themes/` به نام `zaminyab-child` بسازید.
2. یک فایل به نام `style.css` ایجاد کرده و کدهای زیر را قرار دهید:
   ```css
   /*
   Theme Name: ZaminYab Child
   Theme URI: https://zaminyab.ir
   Template: zaminyab
   Version: 1.0.0
   Text Domain: zaminyab-child
   */
   ```
3. یک فایل به نام `functions.php` ایجاد کرده و شیوه نامه‌ها را لود نمایید:
   ```php
   <?php
   add_action( 'wp_enqueue_scripts', 'zaminyab_child_styles' );
   function zaminyab_child_styles() {
       wp_enqueue_style( 'parent-style', get_template_directory_uri() . '/style.css' );
       wp_enqueue_style( 'child-style', get_stylesheet_directory_uri() . '/style.css', array( 'parent-style' ) );
   }
   ```

## 📨 راهنمای اتصال به پنل‌های پیامکی ایرانی (SMS Gateways)
توسعه‌دهندگان گرامی می‌توانند برای ارسال کدهای تایید شماره همراه یا اطلاع‌رسانی از توابع زیر در فایل `functions.php` استفاده نمایند:

### نمونه اتصال به وب‌سرویس فراز اس‌ام‌اس (FarazSMS / IPPanel)
```php
function zaminyab_send_sms_faraz( $to, $code ) {
    $url = 'https://ippanel.com/services.jspd';
    $body = array(
        'op'       => 'pattern',
        'user'     => 'YOUR_USERNAME',
        'pass'     => 'YOUR_PASSWORD',
        'from'     => 'YOUR_SENDER_NUMBER',
        'to'       => $to,
        'pattern_code' => 'YOUR_PATTERN_CODE', // کد پترن تعریف شده
        'input_data'   => json_encode( array( 'code' => $code ) )
    );

    $response = wp_remote_post( $url, array(
        'body'    => $body,
        'timeout' => 15,
    ));

    return ! is_wp_error( $response );
}
```
